test: 0 => ACCEPT

title: Binary Strings (Non-empty)
description: Build a grammar that accepts any non-empty binary string.
test: 1 => ACCEPT
test: 01011 => ACCEPT
test: "" => REJECT
test: 012 => REJECT

title: Even Number of a Characters

title: Simple Arithmetic (Plus Only)
description: Build a grammar that accepts numbers joined by +, for example 1+2+3, with no spaces.

title: Matched Parentheses
description: Build a grammar that accepts correctly balanced parentheses using only ( and ).

test: (()()) => ACCEPT
test: (() => REJECT

title: Comma-Separated Integer List
description: Build a grammar for one or more integers separated by commas, with no trailing comma.

test: 1,2,30 => ACCEPT
test: 1, => REJECT

title: Binary Multiples of 2
description: Build a grammar for binary integers that are multiples of 2 (so the last bit must be 0).

title: Signed Decimal Number
description: Build a grammar for signed decimal numbers: optional + or -, digits, and optional fractional part.
test: 42 => ACCEPT
test: -3.14 => ACCEPT

test: 12. => REJECT
===

title: Mini Expression Parser
description: Build a grammar for arithmetic expressions supporting unsigned integers, addition (+), multiplication (*), parentheses, correct operator precedence (examine the parse tree to check) and left associativity (2+3+4 should be parsed as (2+3)+4 and not 2+(3+4) )
test: 2+3*4 => ACCEPT
test: 7*(1+2*3)+9 => ACCEPT
test: 2**3 => REJECT
test: (3+)*2 => REJECT
===
